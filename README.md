# Business Entity Resolution Using Machine Learning

A scalable machine learning project for identifying
matching businesses across multiple data sources.

## Objectives
- Clean and preprocess business records
- Normalize business names and addresses
- Generate candidate pairs using blocking
- Calculate text similarity features
- Train a machine learning model
- Evaluate matching performance using F0.5

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- RapidFuzz
- LightGBM
- Google Colab

## Project Structure
- src/: Main Python source code
- notebooks/: Experiments and analysis
- data/: Local datasets
- output/: Generated predictions
- models/: Trained models

## Evaluation
Precision, recall, F0.5, candidate recall
and candidate reduction ratio.

## Data
Competition data is not included in this repository.
